# Wild Tech Garden

أنت مصمم UX/UI محترف. أنشئ لي موقع Portfolio تفاعلي لطالبة تونسية في التكنولوجيا.



### [1. الهوية]

الاسم: [حطي اسمك]

المهنة: Développeuse Multimédia & Future Ingénieure Data & IA

الشخصية: مبدعة، طالبة، بناتية راقية، تحب الطبيعة والتكنولوجيا



### [2. الهوية البصرية الكاملة - Wild Tech Girl]

الطابع: "Wild Tech Garden". دمج بين عالم الطبيعة والحيوانات + عالم الكود والذكاء الاصطناعي.



الألوان الإجبارية من الـ Brand:

- Fond: #F9F3D4  بيج عظمي

- Vert Forêt: #3F5E2A  أخضر غابي للعناوين والخطوط

- Orange Brique: #CE3415  برتقالي طوبي للأزرار والـ CTA والـ hover

- Texte: #2D2D2D  بني غامق



الخطوط من Google Fonts:

- Titres: "Playfair Display", serif

- Sous-titres: "Cormorant Garamond", serif  

- Corps de texte: "Poppins", sans-serif



العناصر المميزة:

1.  Illustrations: حيوانات مرسومة Flat Design: غزال، نمر، قرد. بخط واحد بلون #3F5E2A أو #CE3415

2.  Tech Elements: نقاط متصلة تشبه الشبكة العصبية، أقواس { }, أيقونات كود. تكون شفافة 20%

3.  Avatar Personnalisé: صورة كرتونية لي. فتاة تونسية [محجبة/غير محجبة] لابسة نظارات، قاعدة تكود، ستايل لطيف ومهني. ألوانها من الـ Palette.



### [3. هيكل الموقع والتفاعل]

1.  Hero: 

    يسار: Avatar الكرتوني متاعي

    يمين: "Salut, c'est [اسمك]" + "Je transforme des idées en sites web et en IA"

    زرين: [Découvrir mes projets #CE3415] [Mon CV]

    Background: شكل عضوي كبير بلون #F9F3D4



2.  Projets: كروت بيضاء #FFFFFF على خلفية #F9F3D4. 

    عند Hover: الكارت يطلع فيه ظل أخضر #3F5E2A وتظهر أيقونة حيوان صغيرة.



3.  À propos: Timeline على شكل "ساق شجرة" بلون #3F5E2A تمشي مع الـ scroll



4.  Compétences: 3 أعمدة. كل مهارة فيها أيقونة بلون #CE3415



5.  Contact: فورم بسيط. زر الإرسال بلون #CE3415



### [4. لوحة Admin إجبارية]

صفحة /admin بكلمة سر. فيها فورم "Ajouter un projet" بحقول: Titre, Catégorie [Multimédia/IA], Description, Image, Lien GitHub, Outils.

عند الإضافة يظهر تلقائيا في صفحة Projets.



### [5. التقنية]

Next.js 14 + TailwindCSS + Sanity CMS. 

Responsive Mobile First.

Animations ناعمة بـ Framer Motion.

اللغة: Français par défaut + EN



المهم: التصميم يكون فريد، دافئ، أنثوي، ويبين أني طالبة تكنولوجيا مبدعة.





## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Production

```sh
npm run build
npm run start
```
